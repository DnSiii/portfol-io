# Test Card Intelligence

Demonstração de análise de negócios com empresa fictícia e dados simulados.

Acesso: https://dnsiii.github.io/portfol-io/test-card/

Python prepara os números antes da publicação. O site usa HTML, CSS, JavaScript e JSON. Os textos usam linguagem geral; os nomes técnicos internos permanecem para manter a compatibilidade das regras.
