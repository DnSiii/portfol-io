# Test Card Intelligence

Demonstração de analytics operacional com empresa fictícia e dados simulados.

Acesso: https://dnsiii.github.io/portfol-io/test-card/

Os arquivos desta pasta são a publicação estática do painel. Python prepara
os dados e análises antes da publicação; o GitHub Pages serve HTML, CSS,
JavaScript e os dados gerados. Atualizar o BI não atualiza este painel.

Para atualizar, gero novamente os arquivos da demonstração e substituo o
conteúdo desta pasta, preservando o arquivo index.html e a pasta assets.
